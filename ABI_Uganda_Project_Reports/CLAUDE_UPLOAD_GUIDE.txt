AUTHORITATIVE PACKAGE
Use this completed package and the reports inside it. It incorporates the
user's chosen report versions from ABI_Uganda_Project_Reports.zip. Do not

WHAT TO PUBLISH
There are six separate English project reports and matching website
articles. Each numbered folder has:
- index.html: responsive standalone preview.
- article-fragment.html: full illustrated article for integration.
- website-text.txt: the same prose as plain text.
- A PDF report for visitors to download.
- An editable Word master for future changes.
- photos/: edited JPEG and WebP files.
- photo-captions-and-alt-text.csv: ready captions and accessibility text.

Use the website's existing page components, styling and content system.
Keep the text, photo selections and captions aligned with the supplied
reports. Use WebP with JPEG alternatives where the site supports them.
The relative image links in article-fragment.html must be updated if the
files are placed in a different directory. The standalone previews work
with the package folder structure intact.
