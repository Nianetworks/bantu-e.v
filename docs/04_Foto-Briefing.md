# Foto-Briefing

Die Website zeigt bis zum Eintreffen echter Fotos gestaltete Platzhalter mit dem Hinweis, welches Motiv gebraucht wird (Front-Matter-Feld `photoBrief`).

## Wohin mit den Fotos?
- Ablage im Bantu-Archiv: `07_Kommunikation_&_Öffentlichkeitsarbeit/Website/Fotos_fuer_Website/<Projektcode>/`
- Einwilligungen: `02_Datenschutz_&_Privatsphäre/03_Einwilligungen_&_Privacy_Notices/`
- Auf der Website: Bild nach `public/images/projects/<slug>-1.jpg` kopieren, im Projekt eintragen:
  `image: "/images/projects/<slug>-1.jpg"` und `imageAlt: "Beschreibung, was zu sehen ist"`

## Technische Anforderungen
- Querformat 3:2 oder 16:10, mindestens 2000 px breit, JPG, natürliche Farben, keine Filter
- Dateiname ohne Leerzeichen: `p26-230-gruppenraum-2026-11.jpg`
- Für die Website vorher verkleinern (max. 1600 px, ca. 300 KB) – Claude Code kann das übernehmen
- Fotograf*in und Datum notieren (für Bildnachweis)
