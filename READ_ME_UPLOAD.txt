1. Extract this ZIP. Its public/videos folder contains the MP4 and related caption/poster files.
2. Copy those files into the website repository's existing public/videos folder. Keep the filenames, so the supplied website players find them.
3. GitHub accepts the extracted MP4 directly. Uploading only the ZIP does not install a playable website video; Claude must extract and place its contents first.
4. Use the matching language player examples in the separate photos/website package. Narrated films use their own speech caption files and transcript links.
5. Verify playback, captions and seeking on the live page before removing superseded public media.

All six films are required: standard plus spoken-description film in English, German and French. The narrated films are important for accessibility and must be clearly available beside the standard films.
